# Intro to LAN

## Overview
This file introduces Local Area Networks (LANs), common network topologies, and the devices and protocols that enable communication within a network. It also covers subnetting fundamentals, ARP, and DHCP.

## Key Concepts
- Common network topologies:
  - **Star** – Most common; reliable and scalable, but dependent on a central switch.
  - **Bus** – Simple and inexpensive but has a single point of failure and is prone to bottlenecks.
  - **Ring** – Data travels in one direction; resilient to traffic congestion but vulnerable to failures.
- **Switches** connect devices within a LAN and forward traffic only to the intended destination.
- **Routers** connect different networks and route traffic between them.
- **Subnetting** divides a network into smaller subnetworks to improve organization and efficiency.
- A subnet uses:
  - Network Address
  - Host Address
  - Default Gateway
- **ARP (Address Resolution Protocol)** maps IP addresses to MAC addresses for communication within a local network.
- **DHCP (Dynamic Host Configuration Protocol)** automatically assigns IP addresses using the DORA process:
  - Discover
  - Offer
  - Request
  - Acknowledge

## Important Protocols
- **ARP** – Resolves IP addresses to MAC addresses.
- **DHCP** – Dynamically assigns IP configuration to network devices.

## Key Takeaways
- Understanding network topology helps identify strengths, weaknesses, and potential points of failure.
- Switches and routers perform different but complementary roles within a network.
- ARP and DHCP are essential protocols for device communication and network management.
- Subnetting improves network organization, scalability, and performance.
