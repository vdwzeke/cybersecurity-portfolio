# OSI Model

## Overview
This room introduces the OSI (Open Systems Interconnection) model, a seven-layer framework that standardizes how devices communicate over a network. It explains the purpose of each layer, the process of encapsulation, and the role of common networking protocols.

## Key Concepts
- The **OSI Model** consists of seven layers that define how data is transmitted across a network.
- **Encapsulation** is the process of adding information to data as it moves down the OSI layers before transmission.
- The seven layers are:
  1. **Physical** – Transmits data as electrical or optical signals.
  2. **Data Link** – Uses MAC addresses for local network communication.
  3. **Network** – Routes packets using IP addresses.
  4. **Transport** – Ensures data delivery using TCP or UDP.
  5. **Session** – Establishes, manages, and terminates communication sessions.
  6. **Presentation** – Translates, formats, and encrypts data.
  7. **Application** – Provides network services to end-user applications.

## Important Protocols
- **TCP** – Reliable, connection-oriented communication with error checking.
- **UDP** – Fast, connectionless communication without guaranteed delivery.
- **DNS** – Resolves domain names to IP addresses.
- **HTTPS** – Encrypts web traffic to provide secure communication.

## Key Takeaways
- The OSI model provides a standardized framework for network communication.
- Each layer has a specific responsibility and works together to transmit data.
- TCP prioritizes reliability, while UDP prioritizes speed.
- Understanding the OSI model is essential for network troubleshooting, traffic analysis, and cybersecurity.

## Skills Demonstrated
- Understanding the responsibilities of all seven OSI layers.
- Distinguishing between TCP and UDP.
- Identifying where common networking protocols operate within the OSI model.
- Applying the OSI model to analyze network communication.
